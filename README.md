**Website Prompt Generator** is a modern and responsive web application designed to help users create clear, detailed, and AI-ready prompts for website development.
It transforms basic website ideas into structured prompts by allowing 
users to define their website type, design preferences, required features, and content requirements.
Built with **HTML, CSS, JavaScript, and Tailwind CSS**, the application provides a clean, 
intuitive, and responsive user experience, making it easier for developers, designers, and 
beginners to communicate their website requirements effectively with AI tools.
